# Marketing

Material de divulgação do Stway, gerado a partir do conteúdo do app.

| Pasta | O quê |
|---|---|
| `advento-2026/` | Campanha do Advento: `dias.json` (curadoria dos 26 dias) e `KIT.md` (calendário, WhatsApp, Reels, push, Play) |
| `tools/` | Geradores de imagem (Python + Pillow) |
| `out/` | Imagens geradas, fora do git. Regere com os scripts |

A página pública da campanha fica em `site/advento/`.

Para medir o resultado, use o painel admin → **Funil** (retenção D1/D7/D30 por coorte e por trilha de entrada).
