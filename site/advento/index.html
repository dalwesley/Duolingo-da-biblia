Perguntas

É grátis mesmo?
Sim. O Advento 2026 é presente de lançamento: os 26 dias são abertos para todo mundo, sem assinatura.
Perdi um dia. E agora?
Cada cena abre no seu dia e continua disponível depois. Dá para pôr em dia quando puder.
Preciso saber muito de Bíblia?
Não. A cena começa pelo que está escrito no versículo e explica cada resposta. É para quem está começando e para quem já lê há anos.
Dá para fazer com a minha igreja ou célula?
Dá. Mande este link no grupo e combine de fazer a cena do dia juntos. Para usar com a célula, escreva para stway.app@gmail.com.
