# Revisão das frases "Hoje"

Uma linha por cena. Corrija direto em `respostas/lote-*.json` e rode `node scripts/apply_hoje.mjs --no-firestore` para conferir.

## Problemas de conteúdo achados (não corrigidos)

- `deuteronomio-lembrar-02-o-shema` aponta para Dt 31:6–8 (coragem); o Shemá está em `deuteronomio-lembrar-01`.
- `levitico-santidade-02-dia-da-expiacao` aponta para Lv 18:1–5.
- `juizes-juizes-02-gideao` fala de Sansão no contexto.
- `sm-25-frutos-e-casa`: a referência é a casa na rocha, mas título e fatos falam de frutos.
- `hb-boss` (Hebreus) tem o estudo do Shemá do Hebraico em `studies_v3.json`; no `trails.json` do app, o desafio de Hebraico ainda é `hb-boss` (no Firestore já é `hbr-boss`).

Nesses casos a frase segue a passagem, não o título.

Fonte: **mantida** = frase atual do app; **estudo** = frase do estudo V3; **nova** = escrita agora.
